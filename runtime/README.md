# Runtime nativo de corruption3

Este directorio alojará la capa de servicios propia del port. No importa las implementaciones HLE de Mario Kart Wii automáticamente: cada binding de OS, AR, AX, VI, GX, DVD, archivos y módulos debe validarse para RM3E01_00 antes de usarse.

Se podrá reutilizar Aurora y otras dependencias permisivas mediante integración explícita y avisos de licencia conservados. La capa está vacía por ahora; no existe una implementación nativa de Wii.
